# 🎱 마블 룰렛 (Marble Roulette)

구슬을 굴려 당첨자를 뽑는 물리 기반 실시간 추첨기

[![Demo](https://img.shields.io/badge/🎮_Live_Demo-eljja.github.io-blue?style=for-the-badge)](https://eljja.github.io/roulette/)
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

---

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 🎱 **물리 기반 구슬 시뮬레이션** | Box2D (WASM) 물리 엔진으로 구슬 간의 충돌, 튕김, 반발력을 정밀하게 시뮬레이션 |
| 🧑‍💼 **얼굴 사진(증명사진) 커스텀 매핑** | 구슬 클릭 후 `Ctrl+V`로 즉시 사진 등록! 구슬이 굴러갈 때 **물리 회전각에 맞춰 얼굴도 함께 회전** |
| 💾 **이름별 사진 영구 매칭** | 브라우저 `localStorage`에 자동 저장되어 다음 접속 시에도 동일 이름에 사진 자동 유지 |
| 🎵 **배경음악 (YouTube BGM)** | 게임 시작 시 신나는 음악 자동 재생, 추첨 완료 시 페이드아웃 및 자동 정지 |
| 🔊 **풍부한 효과음** | Web Audio API로 구현된 구슬 골인음, 우승 축하 팡파르 등 실감나는 사운드 |
| 🗺️ **다양한 맵 & 🛠️ 맵 에디터** | 기본 제공 맵 외에도 인게임 맵 에디터로 나만의 장애물 코스를 제작하고 URL로 공유 가능 |
| 🏆 **유연한 당첨 범위 설정** | 1등 뽑기, 꼴등(탈락자) 뽑기, 다수 당첨자(N등~M등) 지정 추첨 지원 |
| 🔄 **서바이벌 모드** | 추첨 완료 후 [당첨자 제외하고 다음 판] 버튼으로 연속 서바이벌 진행 |
| ⚡ **스킬 및 충격파 효과** | 구슬들이 멈추지 않도록 무작위 충격파 스킬 발동 옵션 제공 |
| 📹 **자동 화면 녹화** | 경기 시작부터 골인까지의 전 과정을 영상 파일(webm)로 자동 녹화 및 저장 |
| 📋 **프리셋 관리** | 점심 내기, 벌칙 뽑기 등 자주 쓰는 명단을 로컬 프리셋으로 저장/불러오기 |
| 🎨 **다크 / 라이트 테마** | 세련된 네온 다크 모드 및 라이트 모드 전환 |

## 📸 마블 얼굴 사진 등록 및 회전 기능

구슬에 참가자의 실제 얼굴(증명사진)을 쏙 넣어 더욱 몰입감 있고 재미있게 추첨을 진행할 수 있습니다!

1. **마블 선택**: 게임 대기(출발 전) 상태에서 얼굴을 넣고 싶은 **구슬을 마우스로 클릭**합니다. (골드 펄스 링이 반짝입니다)
2. **사진 붙여넣기 (`Ctrl+V`)**: 웹이나 메신저 등에서 사진을 복사(`Ctrl+C`)한 후 화면에서 **`Ctrl+V`** 를 누릅니다.
   - 인물 중심 증명사진에 맞게 **중앙 정사각 자동 크롭 & 원형 아바타**로 압축 처리되어 즉시 적용됩니다.
   - 브라우저에 영구 저장되므로, 추후 동일한 이름을 입력하면 자동으로 사진이 매칭됩니다.
3. **회전 연출**: 구슬이 맵을 타고 굴러떨어질 때 **물리 회전각에 맞춰 얼굴 사진도 함께 자연스럽게 회전**합니다!
4. **사진 삭제**: 구슬을 클릭한 상태에서 **`Delete`** 또는 **`Backspace`** 키를 누르면 얼굴 사진이 즉시 제거됩니다.

## 🎮 게임 조작법 및 단축키

### 단축키 안내

| 키 / 마우스 | 동작 | 설명 |
|---|---|---|
| **마블 클릭 (대기 중)** | 마블 선택 | 얼굴 사진 등록/삭제를 위해 구슬 선택 (골드 링 표시) |
| **`Ctrl+V`** | 사진 등록 | 클립보드 이미지를 선택된 구슬의 얼굴로 등록 |
| **`Delete` / `Backspace`** | 사진 삭제 | 선택된 구슬의 등록된 얼굴 사진 제거 |
| **마우스 휠 스크롤** | 줌 인 / 줌 아웃 | 캔버스에서 화면 확대(Zoom In) 및 축소(Zoom Out) |
| **`Space` / 캔버스 클릭 (주행 중)** | 일시 정지 / 재개 | 경기 진행 중 일시 정지 및 다시 시작 |
| **`Enter`** | 카메라 복귀 | 수동 조작된 카메라를 선두 구슬 자동 추적으로 복귀 |
| **`F`** | 전체 맵 조망 토글 | 맵 전체를 한눈에 내려다보는 와이드 뷰 전환 |
| **`1` ~ `9`** | 순위별 구슬 관전 | 해당 등수(1등~9등)의 구슬로 카메라를 즉시 집중 |
| **`↑ ↓ ← →` (방향키)** | 카메라 수동 이동 | 원하는 구역으로 카메라를 수동 패닝 |

### 참가자 명단 고급 문법

| 입력 형식 | 예시 | 설명 |
|---|---|---|
| `이름` | `철수, 영희` | 기본 1개 구슬 생성 |
| `이름*N` | `철수*3, 꽝*5` | 구슬 N개 일괄 생성 (출현 확률 N배) |
| `이름/W` | `영희/2` | 구슬의 물리 무게(Weight)를 W배로 적용 |
| 복합 사용 | `대표/3*2` | 무게 3배 구슬 2개 생성 |

## 🔧 로컬 개발 및 빌드

```bash
# 저장소 복제
git clone https://github.com/eljja/roulette.git
cd roulette

# 의존성 패키지 설치
npm install

# 로컬 개발 서버 실행 (http://localhost:1235)
npm run dev

# 린트 및 코드 포맷팅
npm run lint

# 프로덕션 빌드
npm run build
```

## 🛠️ 기술 스택

- **Core**: TypeScript 5.6
- **Physics**: Box2D (WASM) 2D 물리 엔진
- **Bundler**: Parcel 2.16
- **Graphics**: HTML5 Canvas 2D Rendering
- **Audio**: YouTube IFrame API (BGM), Web Audio API (합성 효과음)
- **Code Quality**: Biome Linter & Formatter
